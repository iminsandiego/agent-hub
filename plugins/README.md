# Plugin packages

This directory is reserved for future plugin packages and reviewed manifests. Plugin formats differ across clients; keep a source package plus explicitly supported installation adapters. Include version, upstream attribution, dependencies, configuration schema, and removal instructions.

Register an inventory entry in `src/agent_hub/catalog.json`. Keep credentials and machine-specific paths in private runtime configuration. Do not commit tokens, generated client state, or provider accounts.

No third-party plugin has been imported or installed as part of the initial memory-service implementation.
