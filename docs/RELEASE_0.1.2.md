# Agent Hub 0.1.2

Preserve the original recovered 0.1.1 release and add independent home/work server domains, strict client domain/project allowlists, source-cwd checks across available transcript metadata, local backfill planning and separate-profile setup examples.

All archived event payloads, raw strings and stable identities retain their 0.1.1 contract. No existing archive is silently relabeled or migrated. Domain-prefixed projects are selected for fresh separated deployments. No real histories are imported and no existing client configuration is modified during this build.

Read `DOMAINS_AND_INGESTION.md` for deployment, source custody, remote-work routing, native provider homes, capture limitations, historical review, employer approval and future catalog expansion. Read `VALIDATION.md` for executed checks and remaining installation gates.

No public distribution license was selected; the target repository is private. The original conversation and archive hash are recorded in validation provenance. Native prompt caching remains outside the sidecar's control.
