Where do I find a token?

Tokens belong to one server. Use a token issued by the server behind this address, not one from another computer’s service.

Full access (review notes, forget chats): on the server, read the administrator token created by agent-hub init-server, by default ~/.local/share/agent-hub/admin.token.

Browse only: issue a scoped token on the server with agent-hub token create --name browser --project PROJECT --permissions read --output browser.token.

The token stays in this tab’s memory. Reloading or closing the tab disconnects.
