A pasted token stays in this tab’s memory; reloading the page disconnects.

How do I sign in?

Set a password once. On the server, run agent-hub set-password. After that you sign in here with the password, no token needed.

Forgot it? Run agent-hub set-password on the server again. That also signs out every browser.

Tokens are for agents and scripted access. Each belongs to one server; a read-only token for browsing comes from agent-hub token create --name browser --project PROJECT --permissions read --output browser.token.
