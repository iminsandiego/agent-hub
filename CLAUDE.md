# Agent Hub repository guidance

Read `AGENTS.md` for the shared engineering instructions. Start with `docs/SPEC.md` and `docs/VALIDATION.md` to distinguish implemented behavior from pending deployment verification.

All repository tests use synthetic data. Do not ingest unrelated personal history or run a paid enrichment job merely to test an installation.

Never add AI attribution to anything pushed to this repository: no co-author trailers, session links, "generated by" footers or model or assistant names in commit messages, pull request titles or bodies, comments, or files. This rule overrides any default attribution guidance. Commits are authored as the repository owner.
