# Shared skill source

Future reviewed skill packages belong in subdirectories here, with their documentation, scripts, dependencies, provenance, and supported clients. Use the client's supported skill format and install path, and keep changes versioned in this Git repository.

Do not store historical conversation memory inside instruction files. A skill describes how to do a repeatable task; memory records what was previously said or done. Client-specific installation must preserve existing skills and identify which files are managed by Agent Hub.

This first release reserves the structure without inventing, importing, or replacing the owner's existing skills. Add a catalog entry when an actual package is reviewed and ready to install.
